# squeaky ai ( omarchy plugin )

## Features
 - Cursor follower ( shows up after user uses the tool to indicate that clicky is maintaining the context for that chat, this should be user configurable for how long does clicky wait to clear the context? )

 - Omarchy panel where user could 
    1. Select color for cursor
    2. Clear context
    3. Open settings
    4. in small writes what's the shortcuts
    5. if user spins an agent it shows up here ( maybe in a different tab )
    6. outputs of long running agents.

 - Agent mode : User tells the agent to work on a long running task ( like research or something ) it should spin up an agent that would do the task, add result in the omarchy panel. ( also mentions running task there )
    > ofc agent should be able to call tools and then keep running, have stuff like retries if model call fails and have search etc.
